# Biblioteca más amplia y clasificación en segundo plano

- Más espacio para consultar libros: controles superiores compactos, ocultables al desplazarse y recuperables con un botón.
- Nueva vista de renglones con miniatura de portada, título, autor y estado, sin perder las vistas de tarjetas y cuadrícula. Se recuerda la última elegida.
- Clasificar con IA desde la ficha continúa al salir de ella; al volver se recupera el progreso y las categorías se guardan sin eliminar las asignaciones manuales.
