# Canal rápido de posiciones independiente de la biblioteca
Se recupera ReadingPositionSafSync y su formato JSON v1 preexistente. Un JSON propio por dispositivo, peers solo lectura, sin OAuth; no se reescribe ZIP por movimiento una vez configurado el canal. ReaderRepository solicita envío inmediato tras commit local (el lector ya tiene debounce de scroll), con cola conflada y WorkManager persistente de respaldo. El lector consulta los JSON antes de abrir; merge por hash y timestamp de movimiento, no por página máxima ni momento de consulta. Un pull de transición de ZIP y JSON siembra las posiciones más recientes antes del uso rápido; ante fallo o enlaces insuficientes se conserva el camino anterior. El ZIP sigue sincronizando biblioteca, notas y snapshots para backup/compatibilidad en sus tareas normales, no por cada movimiento. Copias de seguridad no modificadas. Ajustes muestra sección visible, último envío JSON verificado y configuración. Los permisos de archivo SAF no permiten inferir permiso sobre hermanos: si no se conservaron JSON anteriores, crear/vincular una vez en cada dispositivo. Los dos equipos deben instalar la actualización. Prueba codec y cronología; pendiente prueba real de Drive y de propagación con dos dispositivos.
