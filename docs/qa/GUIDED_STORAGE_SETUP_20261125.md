# Asistente de configuración de almacenamiento y sincronización
Entrada visible en la biblioteca cuando falta configuración y en Ajustes. Plan de pasos derivado de estado persistido: biblioteca, copia, progreso, dispositivos, verificación. Reutiliza conexiones y omite pasos listos. Un permiso de carpeta SAF permite crear el JSON y copia con nombres automáticos y detectar JSON de peers; en proveedores que solo admiten archivos el selector Android confirma cada ubicación y acceso al otro equipo. No requiere OAuth. No altera ni sustituye los ZIP existentes. La configuración puede pausarse y reanudarse. Avanzado para reparaciones. Prueba del plan y recorrido de Ajustes. Limitación: permisos SAF de Drive por archivo no permiten descubrir hermanos; no se afirma sincronización físicamente verificada.
