# ZIP portable con nombres legibles
La copia completa guarda los originales en books/Título.epub, books/Título.pdf o books/Título.mobi, con sus bytes exactos y sin duplicar archivos. Colisiones de nombres (también en sistemas no sensibles a mayúsculas) se resuelven con sufijos numéricos; caracteres incompatibles con Windows/Android se sustituyen. Los nombres se derivan del título del catálogo, con el nombre de archivo como respaldo. El manifiesto conserva título, autor, nombre de origen, ID, hash, notas, posiciones y demás datos. Se declara el layout named-books-v1. El lector de copias actualizado también acepta el formato anterior books/ID.bin, mantiene las claves internas de restauración y verifica tamaños, hashes y rutas. El contenedor ZIP técnico por dispositivo de la biblioteca compartida no se convierte: sigue usando sus objetos de sincronización; la copia de seguridad portable es el archivo que se descomprime para importar en otros lectores. Los lectores antiguos de BibliotecaAI necesitan actualizarse para restaurar el nuevo layout. Tests de nombres, extensiones, colisiones y restauración antigua.
