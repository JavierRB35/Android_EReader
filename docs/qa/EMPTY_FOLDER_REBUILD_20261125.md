# Reconstrucción de carpeta vaciada
Al ejecutar el asistente sobre la carpeta ya autorizada, la lista real de documentos decide si un URI guardado sigue existiendo. No se interpreta una consulta fallida o un listado en carga como carpeta vacía. Si falta un archivo propio se reconstruye y se eliminan únicamente referencias de configuración obsoletas; los originales, notas, posiciones y la identidad del dispositivo se conservan. Los rollbacks vinculados a documentos desaparecidos se archivan en almacenamiento privado antes de desbloquear la creación. Se crea o reutiliza el ZIP y el JSON propios; no se sobrescribe un archivo de otro dispositivo. La biblioteca reconstruye catálogo y originales desde Room. Se comprueba que todos los originales estén disponibles; si hay un libro sin original local ni remoto, no se inventa ni se elimina sin autorización. Pruebas de reconstrucción del catálogo con carpeta vaciada y dos bases Room, resolución de referencias obsoletas y conservación de rollback, incluidas en el smoke obligatorio.
