# Una sola configuración de almacenamiento
Ajustes reduce biblioteca, copia y posiciones a una tarjeta, con un estado global y un único botón de configuración. Elegir una carpeta autorizada ejecuta toda la preparación automáticamente; el otro dispositivo selecciona la misma carpeta y descubre las posiciones por propietario. Una copia portable por instalación evita escritores simultáneos. Las opciones técnicas anteriores desaparecen de la pantalla. En Drive que no expone permiso de carpeta, el asistente utiliza los selectores individuales imprescindibles de Android: no se inventa permiso de escritura sobre hermanos. Para empezar de cero se elige una carpeta nueva; no se borra el directorio antiguo. Se preservan originales ya registrados, incluidos los que solo estaban en la biblioteca anterior (si no se pueden recuperar se informa y no se cambia la conexión). No se importa un catálogo antiguo para trasladar originales.
Baja definitiva diferenciada de retirar copia local: registro persistente por hash y fecha, migración Room no destructiva v5→v6, propagación en snapshots y copias; filtrado de notas, relaciones y posiciones obsoletas. Un libro reimportado deliberadamente después de la baja puede volver. Las versiones antiguas de ZIP y objetos inmutables externos permanecen como históricos, no se afirma borrado físico remoto. El título mencionado por el usuario no se elimina por coincidencia textual; si aún consta en el catálogo deberá usar Eliminar de la biblioteca una vez. Pruebas de recorrido y de baja frente a instantánea obsoleta. Prueba real de permisos Drive pendiente.
