# Añadir definición como anotación
El emergente Definir presenta un botón Añadir como anotación solo después de obtener una respuesta IA válida y si se capturó un anclaje exacto antes de cerrar la selección. EPUB nativo, Readium, MOBI y PDF OCR reutilizan sus localizadores normales. Se guarda el texto de la definición como NOTE mediante ReadingRepository, sin abrir el editor, sin crear otro subrayado independiente ni modificar notas anteriores. El botón se bloquea durante el guardado; al confirmarse se cierra el emergente. Ante error permite reintentar. Sin cambios en el motor de sincronización o respaldo. Prueba Android con respuesta simulada y persistencia real de una segunda ocurrencia repetida.
