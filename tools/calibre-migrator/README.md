# Migrador Calibre → BibliotecaAI (Windows)
Herramienta independiente y local. Seleccionar carpeta raíz MiBiblioteca (metadata.db si existe; si no, recorrer autor/libro), destino externo, analizar, preparar. Cerrar Calibre durante la operación. No se modifica origen ni se escribe en Drive automáticamente. 
Por defecto un formato por ficha: EPUB > MOBI > PDF (alternativas si un archivo es inválido). Opción conservar todos los formatos compatibles: cada formato distinto cuenta como original separado en BibliotecaAI actual; SHA-256 elimina duplicados exactos en el lote. No se deduplica por título. Lee título, autor y etiquetas del OPF; si no existe usa metadata.db/nombres. No migra imágenes cover.jpg separadas, comentarios, series, campos personalizados, DRM, posiciones o anotaciones Calibre; no se inventan datos. Se preserva portada integrada en el libro. Los formatos no compatibles se omiten y registran por ficha si no hay alternativa.
Genera directorio nuevo con ZIP de migración verificables (máx. 1 GiB y 1000 libros por lote, 512 MiB por original, 16 MiB manifiesto) e Informe.csv. Formato BibliotecaAI BackupCodec v2 y layout legacy books/UUID.bin aceptado por CompleteBackupArchive.read en main 9019da52. Verifica hash y tamaño durante copia y reapertura, nunca sobrescribe ZIP existente. No es copia de seguridad de la biblioteca activa. Se puede usar restauración aditiva actual para materializar libros locales; esperar migración central nueva antes de importar masivamente. No sustituir archivo de biblioteca activa ni ZIP de respaldo. Reimportar puede reactivar bajas previas, revisar antes.
Construcción Windows independiente por Actions, PyInstaller, EXE sin firma Authenticode (SmartScreen puede advertir); checksum. No publica APK ni usa sus credenciales. Pruebas sintéticas Python, falta validar con biblioteca real y lector Android, y conectar ingestión directa del coordinador (PR #99 sucesoras). Mantener paquete como entrada portable, no duplicar lógica de sincronización.
