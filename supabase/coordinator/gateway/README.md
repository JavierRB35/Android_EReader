Definer deliberado con search_path fijo y autorizaciones propias (no Supabase Auth); no SQL dinámico. Bootstrap requiere hash de aprobación aleatoria de un uso provisionado por propietario fuera de GitHub, con caducidad y replay de misma identidad/token; join requiere código emitido por miembro; apply y pull usan autenticación core; revoke bloqueada hasta política autorizada. Es una limitación deliberadamente conservadora para uso privado, no defensa DDoS completa; serializa llamadas de cada bucket.
