# supabase/

Reservado para el **Incremento 5+**: esquema PostgreSQL, migraciones, políticas RLS por usuario, funciones de servidor (Edge Functions) para llamadas a Gemini/Groq sin exponer claves, e índices de búsqueda/embeddings cuando proceda.

El modelo lógico orientativo de entidades está definido en el Prompt Maestro §15.2 (`docs/product/master-prompt.md`).

Reglas: archivos originales de libros en Google Drive (no en Supabase); RLS en lectura/creación/actualización/borrado; ninguna entidad privada sin propietario; nunca publicar claves de servicio.
